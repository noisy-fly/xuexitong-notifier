# 学习通作业截止提醒

一个 Android 学习通作业提醒应用。登录后选择需要关注的课程，查看作业、考试和课程任务，并为有明确截止时间的项目设置提醒。

> 当前为测试版。部分学习通页面可能无法识别，获取结果和提醒时间请以学习通为准。

## 功能

- **选择课程**：只同步所选课程，并在作业专区按课程查看。
- **查看作业**：课程主栏显示明确未完成的项目数量；未完成项目置顶，状态未知其次，已完成置后。已知截止或结束的项目不再显示，截止时间未知的项目会单独标注。
- **章节测试**：在作业专区再次左滑进入章节测试专区，选择课程后按需获取，也可手动更新。已识别明确截止时间的章节测试会出现在作业专区并参与提醒；平台未返回的时间和状态显示为未知。
- **标记状态**：绿色表示已完成，红色表示未完成，黄色表示状态未知。点击未知状态的项目可以在已完成和未完成之间切换；手动标记仅保存在本机，平台返回明确状态时以平台状态为准。
- **手动获取**：随时刷新所选课程；即使已有同步正在运行，也会等待结果。完成后提示成功或部分成功并自动进入课程列表；失败或需要验证时会提示原因。部分来源读取失败时，沿用的旧完成状态显示为未知，避免误判。
- **定时更新和提醒**：可设置更新间隔以及截止前的提醒时间。已完成或截止时间未知的项目不会安排截止提醒。
- **权限状态**：查看通知、电池优化和精确提醒状态，并进入系统设置。

## 安装

1. 前往 [GitHub Releases](https://github.com/noisy-fly/xuexitong-notifier/releases) 下载最新测试版 APK。
2. 在 Android 8.0 或更高版本的手机上安装。
3. 打开应用，使用学习通账号登录，选择需要关注的课程。
4. 点击“手动获取作业”，或开启“应用内定时更新”。需要弹窗时开启“弹窗提醒”，并在“应用状态与权限”中检查系统设置。

正式版 APK 与此前正式版使用相同包名和签名，可覆盖升级。`.debug` 测试版为独立应用，数据不会自动迁移到正式版。

## 使用作业专区

在首页向左滑动，或点击“进入作业专区”，查看所选课程；点击课程进入详情。向右滑动或点击返回按钮可返回上一级。每门课程的数量不包含完成状态未知的项目。

修改课程选择后，应用会取消已移除课程的提醒并尝试同步当前选择。取消全部选择将停止自动更新和作业提醒。

后续同步会先核对学习通列表：本机显示已完成且平台仍显示已完成的作业复用已有详情；章节测试仅在所属小节已完成、此前完整扫描且本机记录均已完成时复用。状态变化、未知或扫描不完整时会重新读取。升级后旧章节缓存需要先重新扫描一次，才能参与优化。若老师在已完成小节中新增测验而平台仍显示小节已完成，可使用“完整扫描本课程”重新读取。

如果学习通要求验证，应用会停止本轮剩余请求并暂停自动更新。点击“打开学习通验证”，由本人完成验证后点击“继续同步”；如果仍无法通过，请稍后重试。

## 检查应用更新

应用启动时会在后台匿名检查 GitHub 的最新正式版（不包含预发行版）。发现新版本时可选择立即更新、忽略此版本或以后再说；“检查应用更新”可手动检查已忽略的版本。下载后会校验安装包大小和 SHA-256，再打开 Android 系统安装界面。

首次使用应用内更新需要先安装包含此功能的正式版；调试版和正式版是独立应用，调试版无法覆盖升级正式版。

## 隐私与权限

账号和密码使用 Android Keystore 加密，保存在应用私有空间中，用于自动登录。课程和作业同步为只读操作。

通知、精确提醒、电池优化和手机厂商的自启动设置会影响后台更新及弹窗是否准时。定时更新间隔最少为 15 分钟，Android 可能因省电策略延迟执行；也可以随时手动获取。

## 已知限制

- 学习通接口可能变化，部分课程、考试或任务数据可能无法完整获取。章节测试按课程单独获取，单次读取有请求上限，读取不全时会提示；测试时样本未提供截止时间或答题时长。出现同步问题时请在应用中查看详情，并以学习通为准。
- 部分项目没有可识别的截止时间或个人完成状态。截止时间未知时不安排定时提醒；状态未知但有截止时间的进行中活动可能触发提醒，通知会标注状态未知。
- 部分剩余时间为估算值，界面会标记“约”。真实截止时间及系统实际到时通知仍需结合设备和学习通页面核对。
- 遇到验证码或学校认证时需要本人处理，应用不会绕过验证。

## 开发与测试

构建 Android 应用需要 JDK 17 和 Android SDK 35。在项目根目录执行：

```bash
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows PowerShell 可将 `./gradlew` 换成 `./gradlew.bat`。调试版包名带 `.debug` 后缀，与正式版独立安装。
